## Version 1.6

Version 1.6 introduces enterprise-grade security controls and on-prem deployment enhancements.

### What's New

- **Geo-Based Access Control** — Restrict privileged access based on geographic location and IP ranges
- **LDAP Proxy** — Full LDAP proxy server for transparent directory integration with PDAccess identity management
- **On-Prem Install Package** — Dedicated on-premises installation package for Enterprises with air-gapped environments
- **Native Terminal & Database Proxy** — Enhanced proxy engine with improved performance and protocol support
- **Hardened Linux Agent** — Security-hardened Linux agent with tamper detection and secure boot support
- **SAML IdP Provider (Beta)** — Advanced SAML configuration with custom attribute mapping and relay state support

### Improvements

- Performance improvements for large-scale deployments (1000+ users)
- Enhanced geo-IP database with improved location accuracy
- Improved Linux agent resource usage and stability
