## Version 1.4

Version 1.4 brings developer-focused APIs and advanced alerting capabilities.

### What's New

- **REST API Support** — Full REST API for programmatic management of users, services, credentials, and policies
- **CLI Application** — Command-line interface for DevSecOps workflows, supporting integration with popular tools (PuTTY, mstsc, etc.)
- **Notification System** — Configurable notifications for credential access, group changes, and service events
- **Alarm Management** — Regex-based system-wide alarms for proxy and logging activities, group-managed alert rules
- **Application-to-Application Password Sharing** — Share credentials via REST calls with JSON, CSV, and XML output formats
- **Permission-Based Credential Sharing** — Share credentials with granular permissions (e.g., can_see_password)

### Improvements

- API documentation and SDK examples for common programming languages
- Improved notification delivery reliability
