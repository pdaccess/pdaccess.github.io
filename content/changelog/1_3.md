## Version 1.3

Version 1.3 adds SAML-based SSO and advanced session management features.

### What's New

- **SAML SSO Support** — Full SAML 2.0 integration for enterprise single sign-on workflows
- **Video Session Recording** — Record terminal sessions in video format for compliance and forensic analysis
- **Time-Based Access** — Schedule access windows with start and end times for just-in-time privileged access
- **Policy Enforcement Engine** — Define and enforce session policies including timeout, command restrictions, and protocol whitelisting
- **Break-the-Glass Credentials** — Emergency access mode with audit logging for critical situations
- **Check-In/Check-Out Mode** — Reserve credentials to prevent concurrent usage conflicts

### Improvements

- Enhanced SAML configuration wizard in the admin console
- Improved session recording storage and playback
