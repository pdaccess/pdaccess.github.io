## Version 1.7

Version 1.7 is the latest release, bringing unified access management and intelligent search to PDAccess.

### What's New

- **Unified Access Without VPN** — Centralized access to all cloud and on-prem resources without VPN or firewall configuration
- **Hybrid Vector Search** — ONNX-based semantic search across assets, credentials, and documentation for faster discovery
- **Polymorphic Asset Management** — Unified inventory for services, vaults, secrets, policies, and JIT access in a single interface
- **Audit Trail Engine** — Comprehensive audit logging for all platform activities with searchable, exportable logs
- **Identity Management** — Enhanced user and group lifecycle management with automated provisioning workflows
- **Cloud Provider Integration** — Native support for AWS, Azure, and GCP with protocol-level access management

### Improvements

- Redesigned administration interface with improved usability
- Significantly faster session connection times
- Enhanced desktop client with improved cross-platform compatibility
- Better Docker image optimization and smaller footprint
- Improved MFA experience with faster verification flows
