## Version 1.2

Version 1.2 introduces enterprise-grade identity management and Linux host security.

### What's New

- **OAuth2 Identity Provider** — PDAccess now acts as an OAuth2 IdP for single sign-on to enterprise applications
- **LDAP/LDAPS Integration** — Connect to existing LDAP directories for user authentication and group synchronization
- **Active Directory Proxy** — Proxy all authentications to your existing Active Directory infrastructure
- **Linux Host Agent** — Agent-based security for Linux/UNIX hosts with authentication, authorization, and accounting (AAA)
- **Sudo Command Control** — Granular authorization for sudo commands on managed Linux hosts
- **Supported Linux Distributions** — RedHat, Oracle, CentOS, and Ubuntu (x86, x86_64)

### Improvements

- OAuth2 and SAML protocol support for enterprise application authentication
- Improved LDAP group management and synchronization
