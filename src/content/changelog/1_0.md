## Version 1.0

Welcome to the first release of PDAccess — the open-source Privileged Access Management platform.

### What's New

- **Desktop Client** — Native desktop application for Mac, Windows, and Linux to securely connect to cloud and on-prem resources
- **CLI Vault Application** — Command-line tool for managing secrets and credentials in the PDAccess vault
- **Administration Console** — Web-based admin panel for managing users, services, groups, and access policies
- **Core Vault Engine** — Military-grade encrypted secret storage with key distribution algorithms
- **Terminal Proxy Support** — SSH, Telnet, RDP, and VNC protocol bridging for secure remote access
- **Basic Activity Monitoring** — Session logging and audit trail for all privileged access

PDAccess v1.0 lays the foundation for secure, compliant access management across hybrid cloud environments.
