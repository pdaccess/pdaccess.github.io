## Version 2.0

Version 2.0 introduces Hybrid Cloud, a flexible deployment model that combines the scalability of cloud SaaS with the control of on-premises installation. PDAccess now lets you split workloads between cloud and local environments to meet data sovereignty, compliance, and performance requirements.

### What's New

- **Hybrid Cloud Architecture** — Deploy select PDAccess components in the cloud while keeping others on-premises or at customer edge locations for optimal data residency and latency
- **Cloud-Hosted SaaS Service** — Fully managed PDAccess cloud platform for authentication, identity management, monitoring, and centralized administration without infrastructure overhead
- **On-Premises Core Services** — Run ws (asset management), pvault (cryptographic vault), and authws (authentication) locally for full data sovereignty and air-gapped deployments
- **Hybrid Sync & Bridging** — Secure, encrypted synchronization between cloud and on-premises instances with real-time replication of identities, policies, and audit logs
- **Intelligent Workload Routing** — Automatically route authentication requests, vault operations, and asset queries to the optimal deployment tier (cloud or local) based on latency, compliance rules, and availability
- **Cloud Failover & Local Autonomy** — On-premises services continue operating independently during cloud outages; automatic re-sync when connectivity is restored
- **Unified Management Plane** — Single dashboard to manage hybrid deployments across cloud and on-premises instances with consistent policy enforcement and visibility

### Improvements

- Enhanced encryption for cloud-to-on-premises data channels
- Optimized synchronization with configurable sync intervals and conflict resolution
- Improved multi-tenant isolation for cloud-hosted deployments
- Streamlined hybrid deployment workflows with guided setup wizards
