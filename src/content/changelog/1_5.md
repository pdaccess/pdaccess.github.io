## Version 1.5

Version 1.5 focuses on modern deployment options and network device security.

### What's New

- **Docker & Docker-Compose Deployment** — Containerized deployment for quick and easy setup
- **Kubernetes & OpenShift Support** — Native Kubernetes deployment with Helm charts for production-grade scaling
- **TACACS+ Protocol** — Terminal Access Controller Access Control System Plus for network device authentication, authorization, and accounting
- **Radius Protocol** — RADIUS authentication support for network infrastructure devices
- **Automation Engine (Beta)** — Automated credential rotation, policy enforcement, and scheduled access provisioning
- **Cisco & Huawei Device Support** — Pre-configured templates for Cisco Catalyst/ASR/Nexus switches and routers, Huawei S5700/AR/CloudEngine devices

### Improvements

- Simplified deployment with Docker images for all PDAccess components
- TACACS+ encryption for secure client-server communication
- Improved Kubernetes resource management and auto-scaling
