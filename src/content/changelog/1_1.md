## Version 1.1

Version 1.1 expands PDAccess with database access capabilities and stronger authentication.

### What's New

- **Database Proxy** — Secure proxy support for PostgreSQL, MySQL, Oracle, and MSSQL databases
- **Multi-Factor Authentication (MFA)** — Three authentication methods: Google Authenticator, SMS, and Email OTP
- **Enhanced Vault Encryption** — Improved key wrapping with 4-layer key hierarchy (Ks → Kv → Ku → DEK)
- **Password Rotation** — Automatic periodic password changes for destination systems (Linux, Windows, SQL databases)
- **Session Recording** — Text-based session logging for all terminal proxy connections
- **User Group Management** — Organize users and credentials into groups for simplified access control

### Improvements

- Performance optimizations for the administration console
- Improved desktop client connection stability
